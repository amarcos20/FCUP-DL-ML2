# Relatórios

Um relatório por notebook/script: o que faz, porquê, o que se descobriu e que decisões daí resultam.
Servem de base para o checkpoint, para os slides e para que todos os membros do grupo saibam explicar todo o trabalho.

| Relatório                                              | Ficheiro                                                         | Resumo                                                                                                                      |
| ------------------------------------------------------- | ---------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| [01_02_eda_preprocessing.md](01_02_eda_preprocessing.md) | `notebooks/01_eda.ipynb`, `notebooks/02_preprocessing.ipynb` | Exploração e pré-processamento: dados disponíveis, rótulos, janelas, entradas da MLP e da CNN, normalização por fold |

Convenções:

- nome do relatório = nome do ficheiro que descreve (`NN_nome.md`);
- figuras em `figures/`, com o prefixo do relatório (`01_eda_*.png`);
- cada relatório termina com **Conclusões / decisões** e, quando faz sentido, **Próximos passos**.
